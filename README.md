# EVOQUE

## ✨ Overview

EVOQUE is a modern clothing e-commerce platform focused on providing a premium shopping experience with a clean UI, responsive design, and a powerful admin dashboard.

This project is designed with scalability, performance, and maintainability in mind.

---

## 🚀 Features

### Customer Website

- Premium Modern UI
- Fully Responsive Design
- Product Categories
- Product Search
- Product Details
- Shopping Cart
- Cash on Delivery (COD)
- User Authentication
- User Profile
- Order History
- Order Tracking
- Dynamic Categories
- Related Products
- PDF Invoice
- SEO Optimized

### Admin Dashboard

- Secure Admin Login
- Product Management
- Category Management
- Order Management
- User Management
- Sales Analytics
- Stock Management
- Coupon System (Future Ready)
